# Samples

All samples are taken from the FluidR3_GM SoundFont (Frank Wen, MIT license).

- `gt_clean/`, `gt_muted/` — Electric Guitar (clean) / (muted), MIDI notes 33–88, pre-rendered by
  https://github.com/gleitz/midi-js-soundfonts
- `drums/` — standard kit one-shots, from https://github.com/surikov/webaudiofontdata
- `bass/` — Electric Bass (pick), MIDI notes 21–52, same source as the guitars
- `cab/cab.wav` — 4x12 guitar cabinet impulse response from https://github.com/olegkapitonov/spiceAmp
  (GPL-3.0), trimmed to 180 ms mono
